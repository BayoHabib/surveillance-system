🎯 Comment utiliser l'éditeur

  1. Capture : Cliquez sur "Capturer et Annoter" pour ouvrir l'éditeur
  2. Choisir un outil : Sélectionnez un outil dans la barre latérale (Flèche, Rectangle, Texte, etc.)
  3. Personnaliser : Choisissez une couleur et ajustez l'épaisseur/taille
  4. Annoter : Cliquez et glissez sur l'image pour dessiner
  5. Texte : Pour le texte, tapez votre message puis cliquez sur l'image
  6. Floutage : Utilisez l'outil "Flou" pour masquer des zones sensibles
  7. Métadonnées : Cochez/décochez les options (horodatage, nom caméra, etc.)
  8. Export : Téléchargez en PNG (haute qualité) ou JPG (optimisé)

⚡ Raccourcis Clavier

  1. ESC : Fermer l'éditeur
  2. Ctrl+Z : Annuler dernière annotation (prochainement)
  3. Delete : Effacer toutes les annotations (prochainement)
